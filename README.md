# Fakhri Manager 3D — النسخة الأولى (v0.1)

لعبة محاكاة مدرب كرة قدم لأندرويد، مكتوبة بـ **Godot 4.2+ (GDScript)**، واجهة عربية RTL مع خيار الإنجليزية.

## الحالة الصادقة للمشروع
**لم يُختبر داخل Godot** (المحرر غير متوفر في بيئة الإنشاء)، فقد تظهر أخطاء بسيطة عند أول تشغيل.

### ما هو منفَّذ
- شاشة البداية، مسيرة جديدة (اسم المدرب + 8 أندية خيالية)، لوحة التحكم
- الفريق: 4 تشكيلات، 5 تكتيكات تؤثر في النتيجة، صفحة اللاعب
- محاكاة مباريات نصية: نتيجة، أحداث بتعليق عربي، إحصائيات
- دوري من 8 فرق (ذهاب وإياب)، ترتيب، هدافون، مواسم متعددة وتطور اللاعبين
- سوق الانتقالات: شراء بعروض (90/100/115%) يعتمد القبول على العرض والميزانية، بيع، كشافة المواهب الشابة، عروض واردة، رواتب أسبوعية
- اللياقة والإصابات، البريد، سجل المدرب
- حفظ تلقائي بعد كل جولة + حفظ/تحميل يدوي (`user://fakhri_save.json`)

### غير منفَّذ بعد
- **ملعب ثلاثي الأبعاد** ومشاهدة اللاعبين (المباراة نصية فقط حالياً)
- اختيار الأساسيين/الاحتياط يدوياً والتبديل أثناء المباراة (التشكيلة تُختار تلقائياً بأفضل لاعبين)
- القائد والركلات الثابتة، التفاوض على الراتب والعقد، الإعارة، تجديد العقود (تُجدَّد تلقائياً)
- شاشة تدريب، كأس وبطولات قارية، مؤتمرات صحفية، رضا الإدارة والجماهير، الإقالة
- أوضاع المحاكاة السريعة/الأبرز، والمهارات التفصيلية للاعب (سرعة، تسديد...)

## التشغيل
1. ثبّت Godot 4.2 أو أحدث (النسخة القياسية GDScript).
2. Import ← اختر `project.godot` ← Run.

## بناء APK
1. حمّل Export Templates من Editor ← Manage Export Templates.
2. ثبّت JDK 17 و Android SDK (build-tools 34، platform-tools، platform 34) ثم اضبط مساراتهما في Editor Settings ← Export ← Android.
3. Project ← Export ← Android (الإعداد جاهز: `com.fakhri.manager3d`) ← Export Project.
   يستخدم Godot مفتاح debug تلقائياً للنسخة التجريبية.

## ملاحظة الخط
